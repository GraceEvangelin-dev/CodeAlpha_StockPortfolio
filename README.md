# CodeAlpha Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker created as part of the CodeAlpha Internship (Task 2).

## Features

- Displays predefined stock prices
- Allows users to enter stock names and quantities
- Calculates the value of each stock holding
- Calculates the total portfolio investment
- Saves the portfolio details to a text file

## Technologies Used

- Python
- Git
- GitHub

## Available Stocks

- AAPL
- TSLA
- GOOGL
- MSFT
- AMZN

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run:

```bash
python stock_tracker.py
